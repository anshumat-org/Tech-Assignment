# UX/UI Design Instructions

**v0.1 DRAFT — 2026-11-06** · Mandatory design principles for all UX/UI assignments. Assignments: see the track README.

| # | Principle | Rule |
|---|---|---|
| 1 | Human-directed design | Design is driven by explicit user needs, requirements and decisions. Understand the problem and the user first. AI assistants may be used but must not invent user research, personas, product behaviour or scope. Record assumptions. Clarify ambiguity instead of guessing |
| 2 | Human-approved design | A human designer reviews and approves AI-generated layouts, flows, copy and assets. This includes accessibility, sensitive-data handling, error and empty states, and any change to an established pattern. The designer is accountable for usability, accessibility and consistency. Explain material decisions |
| 3 | System-first and reusable | Start from the existing design system, tokens and components. Reuse patterns instead of creating one-offs. Design every state: default, loading, empty, error, success, disabled. Do not rely on colour alone. Support keyboard use, readable contrast and small screens. Avoid decoration that does not serve the task |

## What you should be able to demonstrate

- Explain the user need behind each screen and which requirement drove it.
- Identify AI-generated or reused assets and copy, and explain, verify and take responsibility for them.
- Show where shared tokens and components are reused instead of duplicated.
- Show all states for a key flow, including failure and empty.
- Show accessibility checks: contrast, keyboard path, text alternatives, no colour-only meaning.
- Make a small change without breaking consistency across screens.

**Core principle:** AI can assist the work. Humans own the intent, approval and usability.
