# Assignment 01 — Task Dashboard UX

**v0.1 DRAFT — 2026-11-06**

| WH | Answer |
|---|---|
| What | Design a task management dashboard from lightweight research notes to hi-fi screens |
| Why | Tests the full design process: problem framing, flows, structure, visual craft and state coverage |
| Who | Assumed users: a team member tracking own tasks, and a team lead reviewing workload. Candidate states these as assumptions |
| How | Any design tool. Figma link or exported PDF/PNG, plus a short rationale doc |
| When | 6–8 hours of effort. Review 30–45 minutes |
| Where | Desktop first, with a usable small-screen layout |
| Which | Recommended first assignment of the UX/UI track |

## Evaluation weights

| Area | Weight |
|---|---|
| Problem framing and assumptions | 15% |
| User flows and information architecture | 20% |
| Wireframes and hi-fi visual craft | 20% |
| State coverage (loading, empty, error, success, disabled) | 15% |
| Accessibility | 15% |
| System reuse and consistency | 10% |
| Rationale and communication | 5% |
| **Total** | **100%** |

Visual flair is secondary to clear, well-reasoned, complete design.
