# Assignment 03 — Consent Onboarding Flow

**v0.1 DRAFT — 2026-11-06**

| WH | Answer |
|---|---|
| What | A sensitive onboarding flow with plain-language consent cards, error and recovery states, and withdrawal of consent |
| Why | Tests content design, trust, accessibility and care with sensitive data decisions |
| Who | Assumed user: a first-time person asked to share personal details with a fictional service. Candidate states assumptions |
| How | Any design tool. Figma link or exported PDF/PNG, plus a short rationale and content doc |
| When | 5–7 hours of effort. Review 30–45 minutes |
| Where | Mobile first, with a desktop layout. Fictional service and synthetic data only |
| Which | After 01, or on its own for content-heavy and trust-focused roles |

## Evaluation weights

| Area | Weight |
|---|---|
| Consent clarity and plain language | 25% |
| Flow design, error and recovery | 20% |
| Withdrawal of consent | 15% |
| Accessibility | 15% |
| Content design and tone | 10% |
| Sensitive-data handling and visual craft | 10% |
| Rationale and assumptions | 5% |
| **Total** | **100%** |

This is a design exercise, not legal advice. Do not claim legal compliance.
