# Assignment 02 — Design System Starter

**v0.1 DRAFT — 2026-11-06**

| WH | Answer |
|---|---|
| What | A small, documented design system: tokens, 8–10 components with states, accessibility rules, usage guidance, light and dark |
| Why | Tests system thinking, consistency, and the ability to document design so others can reuse it |
| Who | Assumed consumers: designers and developers on a small product team. Candidate states assumptions |
| How | Any design tool. Figma link or exported PDF/PNG, plus a short rationale doc. Tokens as a table or file |
| When | 6–8 hours of effort. Review 30–45 minutes |
| Where | Web product, desktop and small screens |
| Which | After 01, or on its own for system-focused roles |

## Evaluation weights

| Area | Weight |
|---|---|
| Token architecture (naming, layers, theming) | 20% |
| Component design and state coverage | 25% |
| Accessibility rules and verification | 20% |
| Usage guidance and documentation | 15% |
| Light and dark theme consistency | 10% |
| Reasoning and extensibility | 10% |
| **Total** | **100%** |

A small, coherent system beats a large, inconsistent one.
