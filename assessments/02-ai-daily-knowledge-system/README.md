# Assignment 02 — AI-Powered Daily Knowledge System

**v1.0 — 2026-11-06**

| WH | Answer |
|---|---|
| What | A daily note-taking and knowledge app, inspired by Tana, built from structured nodes |
| Why | Tests structured data, local-first behaviour, sync, and safe AI integration |
| Who | Individual users capturing thoughts, meetings, tasks, decisions, ideas |
| How | React or Next.js PWA, IndexedDB, Node.js API, PostgreSQL, provider-independent AI service |
| When | 8–12 hours of effort, 3 calendar day window |
| Where | Runs locally. AI may be a documented mock provider |
| Which | Node types: text, task, meeting, idea, decision, link |

## Evaluation weights

| Area | Weight |
|---|---|
| Database design and data modeling | 20% |
| System architecture and HLD | 15% |
| Frontend and editor implementation | 20% |
| Local-first and sync architecture | 15% |
| AI integration and structured extraction | 15% |
| Code quality and modularity | 10% |
| Testing and documentation | 5% |
