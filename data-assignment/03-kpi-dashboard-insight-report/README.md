# Assignment 03 — KPI Dashboard & Insight Report

**v0.1 DRAFT — 2026-11-06**

| WH | Answer |
|---|---|
| What | A KPI dashboard and a short insight report built on a synthetic dataset, with metric definitions, caveats and a reconciliation |
| Why | Tests whether the candidate can turn data into a trustworthy message: clear definitions, honest charts and stated limits |
| Who | An analyst who reports to non-technical stakeholders |
| How | Any BI tool or code (Streamlit, Metabase, Superset, notebook, static HTML). SQL required for the metrics. PostgreSQL, DuckDB or SQLite |
| When | 6–8 hours of effort. Review 30–45 minutes |
| Where | Runs locally or as exported files, no mandatory paid tool |
| Which | Stage 2 of the Data funnel, after 01. Pairs with 02 for candidates who also build pipelines |

## Evaluation weights

| Area | Weight |
|---|---|
| Metric definitions and reconciliation | 25% |
| Insight quality and recommendations | 20% |
| Caveats, limits and honesty of claims | 20% |
| Chart choice and honest visuals | 15% |
| SQL correctness and reproducibility | 10% |
| Dashboard usability | 10% |
| **Total** | **100%** |

Visual polish is secondary to correct, defensible numbers.
