# Assignment 01 — Accessible Component Library

**v0.1 DRAFT — 2026-11-06**

| WH | Answer |
|---|---|
| What | A small library of 6–8 reusable, accessible UI components driven by design tokens, with a demo page |
| Why | Shows component-first thinking, accessibility fundamentals and API design at small scale |
| Who | Product developers who consume the components and keyboard / screen reader users who depend on them |
| How | Any framework. TypeScript preferred. Tokens from the shared design system or your own |
| When | 4–6 hours of effort. Review about 30 minutes |
| Where | Runs locally. No backend needed |
| Which | Recommended first frontend assignment. Candidates then move to 02 or 03 |

## Evaluation weights

| Area | Weight |
|---|---|
| Accessibility and keyboard support | 25% |
| Component API and reusability | 20% |
| Design token usage and theming | 15% |
| States and edge cases | 15% |
| Testing | 15% |
| Code structure and documentation | 10% |
| **Total** | **100%** |

Visual polish is secondary to correct behaviour.
